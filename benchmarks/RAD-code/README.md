# RAD baseline components used in Ploybook

This directory contains the RAD detector, retrieval index, model backends and
scoring templates used for the RAD-Sim comparison in the ICCC 2026 paper.
The Ploybook evaluation imports these modules directly. The original authors
and license are credited in the accompanying MIT license.

Upstream project: https://github.com/BruceYg/Retrieval-Augmented-Defense

Upstream paper: https://aclanthology.org/2026.acl-long.1895/
